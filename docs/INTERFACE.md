# Interface — Mikael Launcher

## Navegação
A interface usa uma barra lateral esquerda fixa, expandida por padrão. O controle inferior recolhe a barra para uma coluna de ícones. A seção ativa recebe destaque verde e uma indicação visual.

## Seções
- **Início:** painel e atalhos.
- **Jogar:** futura seleção de perfil e motor.
- **Versões:** futuro catálogo e gerenciamento de instalações.
- **Mods:** futuro gerenciamento de mods e modpacks.
- **Downloads:** futuro acompanhamento de arquivos.
- **Configurações:** futuras preferências do launcher.

## Linguagem visual
- Fundo quase preto esverdeado.
- Superfícies em tons de verde escuro.
- Verde vivo para ações e seleção.
- Azul, roxo e amarelo como cores auxiliares.
- Cards arredondados, bordas discretas e tipografia de alto contraste.

## Limites atuais
Os cards de Java e Horizon são informativos. Nenhum motor é baixado ou iniciado nesta etapa. Botões e atalhos só navegam entre as telas já existentes.
